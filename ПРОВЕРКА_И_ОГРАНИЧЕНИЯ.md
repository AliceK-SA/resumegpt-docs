# Что исправлено и что ещё нужно подтвердить

Обновлено 21.11.2026. Это описание изменений в учебном комплекте ResumeGPT, а не акт успешного развёртывания.

## Исправлено

- AsyncAPI 3: AMQP Channel Binding ссылается на весь компонент через `$ref`, исправлено семь каналов.
- OpenAPI: разделены публичная JWT-авторизация и внутренние сервисные токены, добавлены коды `401`/`403`, `429` для запуска анализа, пагинация истории кредитов. Заголовок `X-User-Id` проставляется доверенным шлюзом, не клиентом.
- Резерв кредита: уточнена атомарность условного списания и обработка повторов. Платёж: восстановление после таймаута с постоянным ключом идемпотентности.
- Аренда AI-задачи: ADR-0007 вместо устаревшего ADR-0004, leaseToken/fencing, продление и общий дедлайн. ADR-0008 для неопределённого результата ЮKassa. Старые принятые ADR, кроме разрешённой смены статуса, не переписываются.
- Архитектура: риски персональных данных, отсутствие гарантированных сроков хранения результатов до согласования, предварительные требования к ресурсам, граница между планом и реализацией.
- ЕСПД: соответствие по ГОСТ 19.101-2024, 19.102-77, 19.402-78, 19.404-79, 19.504-79, не по ГОСТ 34.601. Не заявлено полное покрытие ГОСТ 19.404 без оценки технико-экономических показателей.
- Отчёт: исправлены титульные надписи, содержание с подразделами, ссылки на источники, генерация таблиц сервисов и рисков из arc42, разделена мелкая диаграмма последовательности; приложены согласованные DOCX и PDF.
- CI: дополнительная структурная проверка контрактов и Spectral, проверка изменений принятых ADR через сравнение с базой Git; закреплены версии валидаторов. Публикация не проверялась.

## Запущено локально

- `python scripts/check_specs.py`: четыре спецификации, ноль ошибок.
- `python scripts/check_contract_rules.py`: ноль нарушений.
- `python scripts/gen_api_reference.py --check`: справочник актуален после регенерации.
- `python report/extract.py`: восемь ADR, четырнадцать операций HTTP, семь событий/команд, четырнадцать Mermaid-диаграмм, четыре сервиса, девять рисков.
- Проверены синтаксис Python и `node --check` для скриптов отчёта.
- DOCX независимо открыт в LibreOffice и выведен в PDF; число листов и содержание сверены по окончательному PDF.

## Не подтверждено и сознательно не придумано

- Реальный GitHub Pages, настройки ветки `main`, результаты облачного GitHub Actions и screenshot успешного запуска. **Деплой пользователь попросил оставить на потом.**
- Полная `npm`-сборка `report/build.sh` и удалённые CLI (`AsyncAPI CLI`, `Spectral`, `mkdocs`, Mermaid CLI) в этом локальном окружении, где отсутствуют их зависимости. Их необходимо прогнать в GitHub CI перед сдачей.
- Java-реализация и её `pom.xml`, файлы `docker-compose.yml`, фактические версии компонентов и ресурсные измерения; этих файлов нет в предоставленном архиве.
- Юридическое соответствие 152-ФЗ при внешней передаче резюме, действительные сроки хранения результатов и договорные условия Groq.
- ФИО преподавателя и нормоконтролёра; оставлены незаполненные поля.

При включении публикации: провести полный успешный `check → report → deploy`, проверить URL и скриншот, заполнить поля отчёта, затем перестроить DOCX/PDF.
