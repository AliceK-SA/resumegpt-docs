# 12. Глоссарий

| Термин | Значение |
|---|---|
| Анализ (analysis) | Заявка: резюме + вакансия + режим (базовый или продвинутый) и её результат |
| Кредит | Единица оплаты одного продвинутого анализа |
| Резерв (reservation) | Кредит временно заморожен под конкретный анализ. Дальше он либо списывается (commit), либо возвращается (release) |
| Аренда (lease) | Воркер захватил задачу до определённого времени. Пока аренда действует, другие воркеры задачу не берут |
| Сага | Длинный процесс из нескольких локальных транзакций в разных сервисах. При сбое уже сделанные шаги отменяются компенсирующими действиями |
| Компенсация | Действие, отменяющее эффект выполненного шага — например, вернуть зарезервированный кредит |
| Идемпотентность | Повтор того же запроса или события даёт тот же результат, без двойного эффекта |
| Outbox / Inbox | Таблицы исходящих и уже обработанных входящих сообщений в базе сервиса |
| DLQ | Dead Letter Queue — очередь для сообщений, которые не удалось обработать после всех повторов |
| ADR | Architecture Decision Record — короткая запись об одном архитектурном решении: контекст, варианты, решение, последствия |
| arc42 | Шаблон описания архитектуры программных систем из 12 разделов |
| C4 | Модель архитектурных диаграмм из четырёх уровней: контекст, контейнеры, компоненты, код |
| Watchdog | Фоновый процесс в analysis-service, который ищет зависшие заявки и просроченные аренды |
| Outbox-relay | Фоновый процесс, который отправляет сообщения из таблицы `outbox` в брокер |
