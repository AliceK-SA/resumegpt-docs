# ResumeGPT — документация архитектуры

**Команда «CodeCortex»:** Климович Алиса, Петроченко Платон, Хамадалиева Эльвира.

ResumeGPT — AI-консультант по карьере. Пользователь загружает резюме и ссылку на вакансию с hh.ru. Сервис сравнивает их с помощью LLM (Groq) и выдаёт оценку ATS-совместимости, найденные пробелы в навыках, улучшенные формулировки и сопроводительное письмо.

Документация ведётся по принципу «документация как код»: тексты — в Markdown, диаграммы — в Mermaid, контракты — в OpenAPI и AsyncAPI. Всё хранится в Git рядом с кодом, проверяется автоматически при каждом изменении и готовится к публикации на GitHub Pages (факт публикации подтверждается отдельно).

## Соответствие ЕСПД (сопоставление, а не заявление о полном соответствии)

| Раздел ГОСТ 19.402 | Где описано |
|---|---|

| Вызов и загрузка | arc42 [раздел 7](arc42/07-deployment.md) |
| Входные и выходные данные | [Справочник API](api/index.md) |

Стадии разработки программных документов определяются по ГОСТ 19.102-77, виды документов — по ГОСТ 19.101-2024. Для эскизного и технического проектов предусмотрена пояснительная записка (ГОСТ 19.404-79). Наши arc42 и ADR — **содержательные аналоги разделов пояснительной записки**, но не заменяют её автоматически: в частности, отсутствуют измеренные технико-экономические показатели. Справочник API сопоставляется с ГОСТ 19.504-79 и дополнен условиями применения, авторизацией и лимитами; это пока проектная документация, а не руководство к проверенной реализации.

Используемые технические средства и ограничения на ресурсы описаны в [разделе 7](arc42/07-deployment.md). Состав и точные версии ПО уточняются при появлении `pom.xml` и `docker-compose.yml` во второй части. Не следует путать проектную конфигурацию с фактически проверенной сборкой.

## Нормативная основа и ограничения

- ГОСТ 19.101-2024 (виды программных документов), ГОСТ 19.102-77 (стадии разработки), ГОСТ 19.404-79 (пояснительная записка), ГОСТ 19.402-78 (описание программы), ГОСТ 19.504-79 (руководство программиста).
- Соответствие дано по содержанию, а не как подтверждение прохождения нормоконтроля; итоговый документ — отчёт о проектной работе, его код `90` относится к прочим видам документов.
- Проектные показатели эффективности приведены качественно; количественные результаты не измерялись.
